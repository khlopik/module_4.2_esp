# module_4.2_esp

Прошивка для мікроконтролера **ESP32-S3** (4D Systems Gen4 R8N16) на ESP-IDF + FreeRTOS.
Це розширення пари **STM32 ↔ ESP32** із `module_4.1_esp`: логіка кнопки, WS2812 та UART-протокол
збігаються, на додачу тут виводиться поточне значення R/G/B на I2C-OLED-дисплей SSD1306
через LVGL.

## Модулі

| Модуль   | Файл              | Призначення                                  |
| -------- | ----------------- | -------------------------------------------- |
| `button` | `button.cpp/.hpp` | Кнопка на GPIO7                              |
| `led`    | `led.cpp/.hpp`    | Адресний світлодіод WS2812 на GPIO48          |
| `uart`   | `uart.cpp/.hpp`   | Обмін повідомленнями з STM32                 |
| `lcd`    | `lcd.cpp/.hpp`    | OLED SSD1306 128×64 на I2C, відображення R/G/B-барів через LVGL |

## Піни ESP32

| Пристрій     | Пін     | Напрямок | Примітка                              |
| ------------ | ------- | -------- | ------------------------------------- |
| Кнопка       | GPIO7   | вхід     | активний рівень LOW, 50 мс натискання |
| WS2812       | GPIO48  | вихід    | 1 світлодіод, формат GRB             |
| UART2 TX/RX  | GPIO17 / GPIO16 | вихід / вхід | 115200, 8N1          |
| I2C0 SDA/SCL | GPIO6 / GPIO5    | двонапрямний | 400 кГц, адреса 0x3C |

## З'єднання з STM32

| ESP32           | STM32          | Напрямок       |
| --------------- | -------------- | -------------- |
| GPIO17 (TX)     | PA10 (RX)      | ESP32 → STM32  |
| GPIO16 (RX)     | PA9 (TX)       | STM32 → ESP32  |
| GND             | GND            | спільна земля  |

## Протокол UART

Без змін відносно `module_4.1_esp` — 115200 бод, 8N1, текстові рядки ASCII, роздільник `\n`.

**STM32 → ESP32**

| Команда     | Дія                                          |
| ----------- | -------------------------------------------- |
| `ON:1`      | увімкнути WS2812                            |
| `OFF:1`     | вимкнути WS2812                             |
| `R:<value>` | встановити яскравість червоного, 0…255       |
| `G:<value>` | встановити яскравість зеленого, 0…255        |
| `B:<value>` | встановити яскравість синього, 0…255         |

**ESP32 → STM32**

| Команда   | Дія                                                    |
| --------- | ----------------------------------------------------- |
| `PRESS`   | кнопку натиснуто → STM32 вмикає свій вбудований LED   |
| `RELEASE` | кнопку відпущено → STM32 вимикає свій вбудований LED   |

## Логіка роботи

- **Кнопка** — натискання та відпускання надсилають `PRESS` / `RELEASE` на STM32.
- **`ON` / `OFF`** — вмикають або вимккають WS2812. Яскравість компонент зберігається,
  тому `ON` повертає останній встановлений колір.
- **`R` / `G` / `B` зі значенням** — встановлюють яскравість відповідної компоненти
  **та** оновлюють однойменний бар на LCD (висота = `value * 50 / 255`, плюс числова
  мітка з поточним значенням 0…255). Якщо світло ввімкнено, нове значення кольору
  застосовується одразу; LCD-бар оновлюється незалежно від стану WS2812.

## LCD

- Дисплей SSD1306 128×64, монохром, I2C-адреса `0x3C`. RST-пін не використовується
  (`GPIO_NUM_NC`).
- I2C шина на 400 кГц із внутрішніми пулапами (`enable_internal_pullup = true`),
  `glitch_ignore_cnt = 7` для фільтрації коротких сплесків на лінії.
- Вивід організовано через компонент `espressif/esp_lvgl_port` (поверх LVGL):
  створюються три вертикальні бари R/G/B з лейблами та числовим значенням. Усі
  LVGL-виклики обгортаються в `lvgl_port_lock(0)` / `lvgl_port_unlock()`.
- Геометрія барів і початкова висота задані в `lcdConfig::` (`maxBarHeight = 50`,
  `initialBarHeight = 25`). Конвертація RGB → висота бара — `convertRGBValueToBarHeight`
  в `main.cpp`.

## Збірка

```bash
pio run             # збірка
pio run -t upload   # прошивання
pio device monitor  # монітор (115200)
```

Платформа: `espressif32`, плата: `4d_systems_esp32s3_gen4_r8n16`, фреймворк: `espidf`.
Компоненти: `espressif/button`, `espressif/led_strip`, `espressif/esp_lvgl_port`
(підтягує `lvgl/lvgl` 9.6) — усі в теці `managed_components`.
